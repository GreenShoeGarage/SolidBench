From a sketch to a real part.

1. Sketch a rectangle, circle, or closed polygon on XY, XZ, or YZ. Numeric dimensions work without drawing.

2. Extrude to add material, cut it away, or keep an intersection. A cut extends in the positive normal direction from the selected plane offset. XZ’s normal is −Y; YZ’s normal is +X.

3. Refine by editing any feature in the browser or timeline. Select an edge, then add a fillet or chamfer.

4. Export a STEP, STL, native FreeCAD file, or editable JSON project.

Navigation

Left drag: unrestricted orbit. Right drag or Shift + drag: pan. Wheel / pinch: zoom. F: fit. 1 / 2 / 3 / 0: top / front / right / isometric. Ctrl or ⌘ Z: undo. Delete: delete selected feature (undoable). Escape: close dialogs.

Hosting & privacy

Run the included local server or Docker container. Geometry runs in FreeCAD on that host; browser state stays in this browser. No telemetry or external assets. An optional host password protects remote access. The interface and JSON editing can reopen offline after first load; recomputing or exporting solids requires your FreeCAD host to be reachable.

v1.0 boundaries

Use Tools for lofts, circular-profile sweeps, shells, drafts, patterns, body operations, parameters, assemblies and drawings. Sketch constraints are solved by FreeCAD. Assemblies support placement and a grounded fixed, revolute or slider coordinate per component; they do not simulate forces or solve a network of mates. STEP imports retain solids without reconstructing original history. CAM, FEA and sheet metal are outside v1.0. See the included capability matrix for precise limits.

Direct launch

Install the pinned FreeCAD environment once, then use start.command, start.sh or start.bat. No Docker is required. The host needs to stay running for geometry and exports.
