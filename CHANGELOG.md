# Changelog

## 1.0.0 — 2026-10-05

- Made direct Python/FreeCAD installation the primary path; added launch scripts and doctor.
- Added real Sketcher entity/constraint editing, arcs, construction geometry, datum/face planes and solver diagnostics.
- Added schema 2 migration, named arithmetic parameters, multiple bodies, STEP import, per-body exports and checked edge references.
- Added loft, circular sweep, shell, draft, mirror, linear/circular patterns, transform and inter-body booleans.
- Added grounded joint positioning/limits, exact interference, native projected drawing sheets, sections, reference dimensions, tolerances and SVG/PDF.
- Added IndexedDB autosave/recovery and named browser/SQLite revisions with optimistic conflict checks.
- Added host password/session protection, same-origin checks, loopback Host validation, bounded queued/synchronous work, cancellation and worker timeout.
- Improved mobile tool access, parameter editing, validation and failure recovery. Fixed sweep display for degenerate native edges and direct browser launch lifetime.
- Expanded native/server/browser coverage and documented the verified platform and feature boundaries.

## 0.1.0

Initial FreeCAD-backed bracket-to-export vertical slice: primitive and profile solids, booleans, dress-up features, history, viewport, JSON recovery, native exports and printable review.
